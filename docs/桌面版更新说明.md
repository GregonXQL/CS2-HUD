# 2026-10-02 桌面版更新

本次需求取代原 PRD 中“不做小地图”“浏览器控制台”“后端单独部署”的限制。

## 实现

- Electron 启动冻结的 Python 后端，等待健康检查后打开控制台和透明 HUD；窗口启用上下文隔离、沙箱，禁用 Node 集成。HUD 预览也使用桌面窗口。
- Windows 便携 EXE 内置后端、前端、地图和 cfg。启动失败显示错误，日志写入应用数据目录；托盘退出终止后端，父进程异常退出时后端监测并退出。
- 使用 GSI position、forward、bomb.position；异常和缺失向量返回空值。十张固定坐标底图（含补充的 Cache），三张支持分层。
- 小地图为第五个模块，可拖动、缩放、隐藏；旧 JSON 自动补全，不重置其他模块。
- 道具在姓名旁显示为本地 SVG，支持双闪数量、C4。模拟器与离线预览增加示范坐标。
- broadcast_hud.cfg 隐藏常规原生 HUD，保留击杀信息；restore cfg 恢复标准值。没有启用 sv_cheats，没有使用受 cheat 限制的 cl_drawhud 0。

## 验证

- 后端 pytest：36 项通过；前端 Vitest：5 项通过。
- 前端生产构建与 Electron TypeScript 编译通过。
- 冻结后端实际启动，HTTP/GSI、10 人坐标、炸弹位置、五模块布局、地图静态资源检查通过。
- 隐藏 Electron 窗口加载控制台和 HUD，验证图片解码、10 名选手及道具图标；截图位于 overlay/build/control-smoke.png、hud-smoke.png，已查看。
- 修复本机 Conda 虚拟环境的 DLL 收集问题，打包脚本适配 Library/bin。
- 使用最终组装的 release 资源验证桌面启动器：后端 PID 归属正确、地图及前端可读取、停止后端后端口关闭。

Cache 补充：底图与 overview 来自 MurkyYT/cs2-map-icons，原点 (-2000, 3250)，scale 5.5。2048 像素高清底图按 overview 的 1024 逻辑坐标归一化显示，不改变投影比例。可用 `SMOKE_MAP=de_cache` 环境变量运行 desktop_smoke.py 检查 Cache 显示。

真实 CS2 会话尚未验收：不同地图版本的坐标、分层、原生 HUD 隐藏效果和 Windows 覆盖层交互仍需实测。未知地图不会使用错误底图，运行时无需联网下载地图。
