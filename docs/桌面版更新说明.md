# 2026-10-02 桌面版更新

## 固定观察编号排列

选手列表左侧固定 1–5，右侧固定 6、7、8、9、0，对应 GSI observer_slot 0–4 / 5–9。排序不再取决于 A/B 身份或 CT/T 阵营。比分条根据编号组的实际阵营选择对应队名和比分，死亡选手仍参与判断；缺失/无效编号不加入选手列表。

删除控制台的交换阵营按钮、左侧队伍选择器与自动换边开关。保留队名编辑和重新学习名单；队伍身份自动跟随阵营变化。旧配置的手动开关不会覆盖固定编号规则；旧 swap 接口返回 410，队伍修改接口不再接受 a_side、left_slot、auto_swap。

本次需求取代原 PRD 中“不做小地图”“浏览器控制台”“后端单独部署”的限制。

## 实现

- Electron 启动冻结的 Python 后端，等待健康检查后打开控制台和透明 HUD；窗口启用上下文隔离、沙箱，禁用 Node 集成。HUD 预览也使用桌面窗口。
- Windows 便携 EXE 内置后端、前端、地图和 cfg。启动失败显示错误，日志写入应用数据目录；托盘退出终止后端，父进程异常退出时后端监测并退出。
- 使用 GSI position、forward、bomb.position；异常和缺失向量返回空值。十张固定坐标底图（含补充的 Cache），三张支持分层。
- 小地图为第五个模块，可拖动、缩放、隐藏；旧 JSON 自动补全，不重置其他模块。
- 道具在姓名旁显示为本地 SVG，支持双闪数量、C4。模拟器与离线预览增加示范坐标。
- broadcast_hud.cfg 隐藏常规原生 HUD，保留击杀信息；restore cfg 恢复标准值。没有启用 sv_cheats，没有使用受 cheat 限制的 cl_drawhud 0。

## 小地图流畅度与准星更新

GSI 发送节流从 100ms 降为 25ms，取消 100ms 缓冲，后端默认推送上限从 20Hz 提高至 40Hz。前端使用 requestAnimationFrame 对 SVG 选手标记作短时插值，只更新标记属性，不逐帧重绘整个 HUD。朝向取最短旋转路径；超过 250ms 的间断、跨地图/楼层/回合和大幅坐标变化直接定位。插值最多 75ms，不外推位置。

broadcast_hud.cfg 按用户后续要求改为白色静态准星（cl_crosshairstyle 4），大小从 3.9 增为 5，关闭后坐力跟随与武器间距变化，设定 RGB 255/255/255，并关闭观察选手准星覆盖。命令依据 [CS2 ConVar 转储](https://github.com/ArmynC/ArminC-CS2-Cvars/blob/main/cvars/cvarlist.md)。restore cfg 恢复观察选手准星显示，但不还原个人准星样式。此项只需替换游戏中的 cfg 并重新 exec，无需更换 EXE。

本轮验证：前端 8 项、后端 36 项测试通过；构建和 EXE 打包通过；冻结后端与 60fps Electron 离屏检查通过，模拟 GSI 移动时检测到起点、终点之间的实际中间帧。真实 CS2 内的流畅度和准星效果仍需游戏会话验收。
